# YuWen · Personal Website

Demo: https://yuwen0621.github.io/0916/

A clean, fresh, and lightweight personal website for **YuWen**, highlighting academic background, technical skills, research projects, and a synchronized real-time local clock.

---

## 🌿 Overview

This project serves as a personal academic and developer space designed with a soft, natural visual aesthetic. Built using pure vanilla web technologies with zero external dependencies, it focuses on clarity, smooth performance, and essential information.

---

## ✨ Main Features & Functionality

- **Academic & Personal Profile**:
  - **Name**: YuWen
  - **Department**: Department of Computer Science and Engineering
  - **About Me**: Born on June 21 · Female · Taiwan
- **Real-Time Synchronized Clock**:
  - Live digital clock displaying hours, minutes, and seconds (`HH:MM:SS AM/PM`) with 1-second precision.
  - Full calendar date and day-of-the-week tracking.
  - Localized to Taiwan / Asia/Taipei (`UTC+8`).
  - Dynamic time-of-day greeting (Morning, Afternoon, Evening).
- **Technical Skills**:
  - Dedicated badges for core programming languages: **Python**, **C/C++**, and **MATLAB**.
- **Research Project Showcase**:
  - Featured research card for **DA-MedRGAT** (*Domain Adaptation and Medical Relational Graph Attention Network*).

---

## 🎨 Design & Aesthetic Highlights

- **Light Yellow & Sage Green Palette**: A soothing, organic color scheme with warm buttercup accents, fresh matcha green highlights, and an ivory base.
- **Subtle Checkered Pattern**: Delicate pure CSS repeating grid creating a gentle, natural texture without cluttering the page.
- **Zero External Images**: Rendered entirely through pure CSS, modern typography (Outfit, Plus Jakarta Sans, JetBrains Mono), and lightweight vector SVGs.
- **Responsive Layout**: Fluid grid and flexbox layout optimized for desktop, tablet, and mobile screens.

## 🛠️ Built With

- **HTML5**: Semantic document structure
- **CSS3**: Custom properties, CSS grid/flexbox, and pure CSS patterned backgrounds
- **JavaScript (ES6+)**: Real-time clock and dynamic greeting engine

## 🚀 Running Locally

No installation or build process is required:

1. Clone or download the repository:
   ```bash
   git clone https://github.com/yuwen0621/0916.git
   cd 0916
   ```
2. Open `index.html` directly in any web browser, or launch a simple local HTTP server:
   ```bash
   python -m http.server 8080
   ```
3. Visit `http://localhost:8080` in your browser.
